# Level 4 Advanced Control (간접 명령 처리 및 시각화)

CARLA 시뮬레이션 환경에서 사용자의 일상적인 대화나 간접적인 명령을 파악하여 차량을 제어하고, 차량 위(HUD)에 시각적 텍스트 메시지를 출력합니다. 
`indirect_command.py`를 호출하여 사용합니다.

## 간접 명령 패턴
스크립트는 인자로 전달된 문장에 포함된 키워드에 따라 아래와 같이 반응합니다.

- **어두울 때 (어둡, 라이트)**
  - 예: "밖이 어두운 것 같은데"
  - 액션: 헤드라이트(LowBeam + Position) ON
  - 피드백: "주변이 어두워 헤드라이트를 켭니다."

- **더울 때 (덥, 에어컨)**
  - 예: "아, 좀 덥네"
  - 액션: 에어컨 설정 (HUD 텍스트 피드백)
  - 피드백: "실내 온도가 높습니다. 에어컨을 22도로 조절합니다."

- **환기가 필요할 때 (답답, 창문)**
  - 예: "공기가 좀 답답한 것 같아"
  - 액션: 차량 전체 문(Door) 개방 (창문 대체)
  - 피드백: "환기를 위해 창문을 개방합니다."

- **피곤할 때 (피곤, 마사지)**
  - 예: "오늘 좀 피곤하다"
  - 액션: 실내등(Interior Light) 점등
  - 피드백: "피로 회복을 위해 시트 마사지 기능을 시작합니다."

- **졸음 감지 (졸, 졸리, 잠)**
  - 예: "너무 졸리네"
  - 액션: 비상등 ON + 차량 정지 + 모든 문 개방
  - 피드백: "졸음이 감지되었습니다. 안전을 위해 차량을 정지하고 문을 개방합니다."

- **위험 상황 (위험, 멈춰, 스톱)**
  - 예: "앞에 위험해! 멈춰!"
  - 액션: 비상등 ON + 차량 즉시 정지(핸드브레이크 포함)
  - 피드백: "위험 상황이 감지되었습니다. 즉시 차량을 정지합니다."

- **도착 및 하차 (도착, 내릴게, 세워)**
  - 예: "이제 도착했어. 내릴게."
  - 액션: 모든 문 개방
  - 피드백: "목적지에 도착했습니다. 문을 열겠습니다. 안녕히 가세요!"
